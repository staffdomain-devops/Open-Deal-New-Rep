## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Information Disclosure | ANTHROPIC_API_KEY | mitigate | Key read via os.environ["ANTHROPIC_API_KEY"] (fail-fast); never logged, never written to any output file; key never appears in DLQ or print output |
| T-04-02 | Tampering | brief_text content (prompt injection) | accept | brief_text is assembled by Phase 3 from validated HubSpot record fields (no user-supplied free text); risk is low — brief_text influences tone/content of generated emails only, not code execution or data writes |
| T-04-03 | Denial of Service | max_tokens truncation | mitigate | stop_reason == "max_tokens" raises MaxTokensError before parse; contact goes to DLQ; run continues to next contact without abort |
| T-04-04 | Information Disclosure | raw model response saved to raw_response_{id}.txt | mitigate | File written to RUNNER_TEMP (ephemeral CI runner storage); never uploaded as artifact; path only logged to stderr, not to external systems |
| T-04-05 | Tampering | generated_{id}.json written after partial parse | mitigate | write_generated called only after parse_output returns cleanly (after all 8-key and sub-key validation passes); no partial write on failure |
| T-04-06 | Information Disclosure | contact PII in DLQ failed_contacts.json | accept | DLQ contact_email is "" for Phase 4 (brief has no email); contact_id (HubSpot numeric ID) is low-sensitivity; failed_contacts.json uploaded as artifact only on failure (Phase 7 CI-04) |
